# baxi-guard: модератор для Бакси

Отдельный Telegram-бот, который наводит порядок в чатах: мут, бан, предупреждения, стоп-слова, антиспам,
чистка служебных сообщений, режим атаки и журнал. Живёт рядом с Бакси на том же сервере, со своей базой,
и общается с ним через внутренний API на 127.0.0.1. ТЗ: `docs/GUARD_SPEC.md` в репозитории dalmatinec/baxi.

Участникам бот не виден, пока они не нарушат. Всё автоматическое в новом чате выключено, админ включает сам.

## Кто что может

Админка в Telegram сама ничего в боте не даёт. Роли:

| Роль | Что может | Как назначить |
|---|---|---|
| 👑 Владелец | создатель чата и владелец бота (`OWNER_IDS`): всё, назначает и снимает админов | сам |
| ⭐ Админ | всё в чате: модерация, игры, триггеры, настройки, тексты, белый список, назначает модераторов | `/adm` ответом (только владелец) |
| 🛡 Модератор | мут, предупреждения, бан и кик, удаление и закреп, игры, триггеры | `/mod` ответом (админ или владелец) |

`/unmod` ответом снимает роль, `/mod` без ответа показывает, у кого какая роль. В личке: ⚙️ чат → 👥 Роли.
Белый список: `/trust` и `/untrust` ответом. На каждое назначение и снятие бот пишет сервисное сообщение,
его текст меняется в ✉️ Тексты. Меню команд в чате человек видит по своей роли: участникам только /profile и /stat.
Автоматика не трогает админов Telegram и всех, у кого есть роль.

## Игры, триггеры, профиль, перенос

* **Рулетка:** `/game` → по хэштегу или обычная. Список закрепляется сам (и при повторном открытии), под ним
  Записаться, Выписаться, 🔒 Закрыть список, 🎯 ФК. У каждой кнопки есть команда: `/close`, `/open`, `/fk 30`,
  `/leave`, `/list` (показать список заново), `/random 36` (только число), `/endgame`. ФК по желанию, в любой момент.
  Обычный раз, топ два («+топ», «+топ игра», «+топ 3д», «-топ»). «+в список», «убрать 5».
* **Триггеры** (модератор и выше): в чате ответом на сообщение «+триггер слово» (текст с премиум-эмодзи, пересланное,
  фото, видео, гифка, стикер, голосовое, файл), «-триггер слово» удалить, «триггеры» список.
  То же в личке: ⚙️ чат → 🧩 Триггеры.
* **Профиль:** `/profile` или «профиль» (ответом: чужой). Репутация, ранг и монеты от Бакси по API.
* **Активность:** `/stat` или «стата», «актив» (для всех, участникам не чаще раза в 10 секунд на чат): сообщений
  и сколько человек писали за этот час, сегодня, 7 дней или всё время, топ-10. Период кнопками под карточкой.
  Имена без ссылок, топ никого не будит. Текст карточки меняется в ✉️ Тексты (📊 Активность).
* **Тексты:** ⚙️ чат → ✉️ Тексты: любое сообщение бота можно переписать (с премиум-эмодзи), добавить картинку
  и кнопки. Нажали ✏️ Текст: бот сначала присылает текущий текст как есть, его можно скопировать, поправить
  в Telegram (добавить премиум-эмодзи) и прислать обратно. Порядок: текст чата → текст бота для всех → стандартный.

## Приветствие, капча, свой ник, настройки в чате

* **Приветствие:** ответьте `+приветствие` (или `/setwelcome`) на любое сообщение, и оно сохранится копией,
  не пересылкой: текст с премиум-эмодзи и шрифтами, картинка, видео или гифка. Строки в конце вида
  `Текст - ссылка` (в ряд через `|`) станут кнопками. Можно и без ответа: `+приветствие Привет, {user}!`.
  Подстановки: `{user}` (имя ссылкой), `{name}`, `{username}`, `{chat}`, `{count}` (какой по счёту).
  `-приветствие` выключает, `приветствие` показывает. В личке: ⚙️ чат → 👋 Приветствие: удалять через
  1/5/15/60 мин, новое убирает прошлое, фраза Бакси после приветствия.
* **Бакси и приветствие:** пока в чате включено приветствие или капча, Бакси сам на вход не здоровается.
  Гард встречает новичка (после капчи), и Бакси следом добавляет свою фразу, если в Бакси включено
  «здороваться» и в Гарде не выключена «Фраза Бакси».
* **Капча** по желанию: `капча кнопка` («Я не бот»), `капча пример` (выбрать ответ), `капча эмодзи` (нажать
  названное), `капча выкл`. Пока не прошёл, писать нельзя. Время 1/3/5/10 мин и что делать с не прошедшими
  (удалить, оставить без права писать, забанить) в личке. Тексты капчи меняются в ✉️ Тексты.
* **Свой ник** (`NICK_PRICE`, по умолчанию 5 000 монет Бакси, смена столько же): в личке бота кнопка
  «✨ Мой ник». Присылаешь ник как хочешь: жирный, курсив, подчёркнутый, зачёркнутый, спойлер, до 3
  премиум-эмодзи в начале или в конце, до 24 символов. Бот показывает, как будет, кнопка «Купить»,
  монеты списывает Бакси (двойное нажатие не спишет дважды). Ник виден во всех упоминаниях Гарда и Бакси.
  Владелец бота убирает чужой ник ответом `-ник`.
* **Настройки:** `/settings` (если в чате Бакси: `/settings@бот`) или слово `настройки` в чате дают кнопку,
  которая открывает настройки именно этого чата в личке. В самом чате настройки не показываются.
* **Роли одной командой:** `роль` (`/role`) ответом, роль выбирается кнопкой: ⭐ Админ (все права, только
  владелец назначает), 🛡 Модератор, 🔰 Мл. модератор (мут, предупреждения, удаление), 🎮 Ведущий игр
  (только игры). Админ назначает модераторов, младших и ведущих. Сразу: `/role mod|junior|host|admin|none`.
  Белый список: `/allow`, `/unallow` (старые `/trust`, `/untrust` тоже работают).
* **Латиница:** у каждой русской команды есть латинская: `+trigger`, `-trigger`, `/triggers`, `/top`,
  `/untop`, `/add`, `/remove 3`, `/random`, `/close`, `/fk`, `/leave`, `/role`, `/info` и т.д.
* **Паспорт чата:** `инфо` (`/info`) и сам при добавлении бота: команда, что включено из защиты, как встречают
  новичков, есть ли Бакси, за 7 дней сообщения, новички, удалённый спам и наказания, тариф, ID.
* **Профиль в личке:** кнопка «👤 Профиль»: ник, баланс и уровень у Бакси, стикер профиля. Стикер приходит
  в чате перед карточкой профиля.

## Супер-админка: только владелец бота (/admin или /start → 🛠 Супер-админка)

* **✉️ Тексты бота:** те же тексты, но сразу для всех чатов. Где админы чата поставили свой, остаётся их.
* **🎨 Кнопки:** цвет (синяя, зелёная, красная, без цвета) и премиум-значок любой кнопки бота, в личке и в чатах.
  Кнопка узнаётся по своему виду, а не по чату: «удалить триггер» перекрасится во всех чатах сразу.
  «🎯 Выбрать нажатием», потом нажать нужную кнопку где угодно: вместо действия откроется её настройка.
* **Кнопки в текстах** (реклама и ссылки): цвет `#синяя` `#зелёная` `#красная` в конце строки и премиум-эмодзи
  в начале как значок ставит только владелец. У админов чатов это просто убирается.
* **✨ Эмодзи:** обычные эмодзи во всех сообщениях и на кнопках бота меняются на премиум-версии.
* **Перенос:** ⚙️ чат → ℹ️ О чате → 🧰 Перенести: настройки, стоп-слова, домены, права, тексты, триггеры,
  топы и предупреждения копируются в другой чат.

## Команды в чате

Цель: ответом на сообщение, `@username` или числовым ID после команды. Время: `30m`, `2h`, `3d`, `1w`
(можно и `30м`, `2ч`, `3д`, `1н`). Причина: всё после времени.

| Команда | Что делает |
|---|---|
| /mute [время] [причина] | запретить писать, без времени на 1 час |
| /unmute | снять мут |
| /warn [причина] | предупреждение; на лимите (по умолчанию 3) мут или бан, как настроено |
| /warns | предупреждения человека (ответом, для модераторов) или свои |
| /unwarn | снять последнее предупреждение |
| /ban [время] [причина] | бан, без времени навсегда |
| /unban | разбан |
| /kick | выгнать без бана |
| /pin, /unpin | закрепить или открепить |
| /link | ссылка-приглашение |
| /del | удалить сообщение и саму команду |
| /attack [время] | режим атаки вкл/выкл |
| /whitelist | ответом: в белый список или из него; без ответа: список |
| /mod | ответом: модератор бота или нет; без ответа: список |
| /settings | кнопка в личку к настройкам этого чата |
| /chat | ID чата, режим, каких прав не хватает боту |
| /v | пинг |

Команда удаляется через 5 секунд, ответ бота через 60 (меняется в настройках, 0 значит не удалять).
Если в чате есть Бакси (`BAXI_BOT_ID` в .env), на голую `/settings` отвечает он, а модератор на
`/settings@имя_модератора` (из меню команд Telegram подставляет имя сам).

`@username` бот находит только среди тех, кого видел в чатах: Telegram не даёт ботам искать людей по нику.

## Автоматическая защита

Каждая включается отдельно в ЛС: /settings → чат. Настройки чата разложены по категориям:
🛡 Защита (антиспам, стоп-слова, режим атаки), 🧹 Чистота (служебные, автоудаление команд и ответов),
⚠️ Наказания, 👥 Доверие (белый список, модераторы бота, домены), 📜 Журнал, ℹ️ О чате (ID, права бота).

Премиум-эмодзи: владелец присылает их в /admin → ✨ Эмодзи, и каждый заменяет свой обычный двойник
во всех сообщениях и значках кнопок (нужен Telegram Premium у владельца бота).

* **Стоп-слова.** Текст нормализуется: регистр, ё/е, латинские двойники букв, повторы (`плохоооой`),
  знаки между буквами (`п.л.о.х.о`, `п л о х о`). Слово ловится с окончаниями, короткие (до 3 букв) только
  целиком. Проверяются и отредактированные сообщения. Действие: удалить, удалить и предупредить, удалить и мут на час.
* **Антиспам.** Не трогает админов, модераторов бота, белый список и доверенных у Бакси. Ловит ссылки на сайты
  (кроме доменов из белого списка чата), приглашения `t.me/+`, `joinchat`, ссылки на чужие каналы и ботов,
  упоминания `@канала`, пересылки, кнопки-ссылки, скам (заработок в день, "пиши в лс", раздачи, кошельки,
  номера карт по Луну). Новичкам (первые 24 часа или первые 5 сообщений) любая ссылка удаляется.
  Спорные сообщения можно отдать нейросети (нужен `AI_API_KEY`, галка в чате, лимит в сутки), по умолчанию выключено.
  Действие: удалить, удалить и предупредить, удалить и мут на час, бан. Одного человека наказываем не чаще
  раза в минуту, удаляем всё.
* **Служебные сообщения:** вошёл, вышел, закрепил, фото чата, название чата, каждое отдельной галкой.
* **Режим атаки:** каждого нового участника сразу выгоняет. Включается кнопкой или /attack, выключается сам
  через 30 минут (настраивается). Автовключение: больше 10 входов за минуту.
* **Журнал:** каждое действие в базе (90 дней). Можно указать чат или канал, туда идёт строка: кто, кого,
  что, причина, ссылка.

## Внутренний API

Слушает только `127.0.0.1:GUARD_API_PORT`, каждый запрос с `X-Key: <BAXI_API_KEY>`, иначе 401.
Без ключа в .env сервер не поднимается.

| Запрос | Ответ |
|---|---|
| `GET /v1/ping` | `{"ok": true, "version": "0.1.0"}` |
| `GET /v1/user/{chat_id}/{user_id}` | `{"warns": 1, "warn_limit": 3, "muted_until": 0, "banned": false, "muted": false}` |
| `GET /v1/chat/{chat_id}/stats?days=1` | `{"mute": 2, "warn": 3, "ban": 0, "kick": 0, "spam": 5}` |
| `GET /v1/chat/{chat_id}/settings` | `{"known": true, "active": true, "stopwords": false, "antispam": true, "service": false, "attack": false, ...}` |

`muted_until` для мута навсегда: 4102444800 (2100 год), плюс `"muted": true`.

Модератор сам ходит к Бакси: `GET /v1/chat/{id}` (оплачен ли чат, кеш 10 минут), `GET /v1/chat/{id}/trusted`
(кеш 5 минут) и шлёт `POST /v1/events` (warn, unwarn, mute, unmute, ban, unban, kick, spam).
Если Бакси недоступен, событие ложится в `outbox` и досылается раз в минуту, старше суток выбрасывается.
Таймаут 3 секунды. Пока у Бакси нет API, модератор работает сам по себе.

### API для веб-админки

Тот же порт, свой ключ `X-Key: <WEB_API_KEY>` (ключ Бакси сюда не подходит и наоборот). Веб-админка будет
на этом же сервере. Тексты и кнопки те же, что в боте. Премиум-эмодзи в поле `text` видны с ID:
`{emoji:5368324170671202286:🔥}`, в поле `html` как у Telegram. Сохранять можно любым из двух, HTML
проверяется (только теги Telegram, всё закрыто). `chat=0`: тексты бота для всех чатов.

| Запрос | Что |
|---|---|
| `GET /v1/admin/meta` | разделы текстов, цвета кнопок, форматы |
| `GET /v1/admin/chats` | чаты бота |
| `GET /v1/admin/texts?chat=0` | все тексты: `default`, `common` (для всех), `own` (свой), `effective` (какой действует) |
| `GET/PUT/DELETE /v1/admin/texts/{key}?chat=0` | один текст; PUT `{"text"\|"html", "photo", "buttons"}`; DELETE вернуть как было |
| `GET /v1/admin/buttons` | виды кнопок с цветом и значком |
| `PUT /v1/admin/buttons/{id}` | `{"style": "primary\|success\|danger\|plain\|", "icon": "ID\|"}` |
| `GET /v1/admin/emoji` | набор премиум-эмодзи |

Как это вместе: в вебе поставили «Привет» → в боте ✏️ Текст, бот прислал «Привет» → скопировали, добавили
премиум-эмодзи, прислали → сохранилось, и веб в следующий раз покажет `{emoji:ID:🔥} Привет`. У каждого
текста есть `updated_at` и `updated_by` (ID в боте или `web`).

`GUARD_NEEDS_BAXI_PAID=1`: работать только там, где Бакси оплачен или на пробном, либо есть своя подписка
(владелец: /admin → чат → Своя подписка). Если Бакси не отвечает, чат считается разрешённым.

## Тестовый стенд (сначала здесь)

Копия Бакси из ветки с правками и модератор на тестовых токенах, рядом с боевыми, ничего у них не трогая:
свои папки (`/opt/baxi-test`, `/opt/baxi-guard-test`), свои базы, свои сервисы (`baxi-test`, `baxi-guard-test`),
свои порты (8720, 8721), свой ключ API. Боевой токен скрипт не примет.

```bash
git clone -b guard-v1 https://github.com/dalmatinec/baxi-guard /opt/baxi-guard-test
bash /opt/baxi-guard-test/deploy/test-stand.sh install   # спросит два тестовых токена, твой ID, ключ ИИ
```

| Что | Команда |
|---|---|
| Свежий код из веток | `bash /opt/baxi-guard-test/deploy/test-stand.sh update` |
| Сменить тестовые токены (ввод скрыт, Enter: оставить) | `bash /opt/baxi-guard-test/deploy/test-stand.sh tokens` |
| Живы ли | `bash /opt/baxi-guard-test/deploy/test-stand.sh status` |
| Логи обоих | `bash /opt/baxi-guard-test/deploy/test-stand.sh logs` |
| Остановить | `bash /opt/baxi-guard-test/deploy/test-stand.sh stop` |
| Снести стенд | `bash /opt/baxi-guard-test/deploy/test-stand.sh remove` |

После утверждения ветки сливаются, и боевые обновляются как обычно (ниже).

## Перенос чата, владелец, поддержка

* **🧰 Перенос чата** (личка → «🧰 Перенос чата» или ⚙️ чат → ℹ️ О чате): откуда → куда → что. Откуда можно и из
  чата, где бота уже нет (чат удалён, заблокирован, бота убрали): бот помнит его настройки, роли и тариф, права
  проверяет по памяти (последний создатель, владелец в боте, роли из базы). Всегда переносятся настройки,
  тексты, триггеры, стоп-слова, домены, топы; по выбору роли и белый список, заместитель, предупреждения,
  бан-лист (бот банит тех же в новом чате в фоне), активность, тариф (уходит из старого; пришедший переносом
  тариф 30 дней дальше не передаётся), данные Бакси (`POST /v1/chat/move` у Бакси: аренда, репутация, память).
* **👑 Владелец** (⚙️ чат → 👑 Владелец): бот раз в 6 часов сверяет создателя. Владелец назначает 🛟 заместителя.
  Аккаунт владельца удалили или заблокировали: заместитель в личке «🔑 Права владельца» → запрос; владельцу
  в личку и в чат уведомление, срок на отказ 72 часа (заместитель админ), неделя (участник), сутки (создателя
  в чате уже нет). Никто не отклонил: заместитель владелец в боте (все права бота в чате, как у создателя).
  Без заместителя: обращение в поддержку, разработчик `/setowner ID_чата ID_человека` (0: снять).
* **🆘 Связь с разработчиком** (личка): чат → тема → сообщение (можно скриншот). Разработчику (`SUPPORT_CHAT_ID`
  или владельцам бота в личку) приходит карточка: автор и его роль, чат, участники, права бота, Бакси, тариф,
  владелец и заместитель, защита, действия за сутки, версия. Ответ кнопкой или ответом на сообщение,
  кнопки «Закрыть» и «Сделать владельцем в боте». Лимиты: 3 открытых, 5 в сутки, 3000 символов.
* **Лимиты:** кнопки 20 нажатий за 10 секунд на человека, личка 15 сообщений за 30 секунд, команды участника
  6 за 20 секунд в чате (команда бота без лимита). Отправка в очереди под Telegram: 20 в минуту в группу,
  1 в секунду в личку, 25 в секунду всего.

## Новый сервер: оба бота, по порядку

**Новый Бакси с новым токеном** (старый на старом сервере работает дальше), от root, Ubuntu 24.04:
```bash
git clone -b guard-v1 https://github.com/dalmatinec/baxi-guard /opt/baxi-guard
bash /opt/baxi-guard/deploy/new-server.sh
```
Делает всё по порядку: защита сервера (`server.sh`), Бакси из ветки guard-api в `/opt/linkhub` (спросит токен,
твой ID и ключ нейросети, ввод скрыт), Гард в `/opt/baxi-guard`, общий ключ API и адреса в оба `.env`
(`guard-link.sh`), проверка. Нейросеть по умолчанию DeepSeek (`AI_MODEL=deepseek-flash`), другой сервис:
`AI_BASE_URL` и `AI_MODEL` в `/opt/linkhub/.env`.

**Перенести старого Бакси со всеми чатами и подписками** (тот же токен) вместо нового:
```bash
bash /opt/baxi-guard/deploy/server.sh
bash /opt/baxi-guard/deploy/move-baxi.sh check IP_СТАРОГО   # проверка, ничего не меняет
bash /opt/baxi-guard/deploy/move-baxi.sh move IP_СТАРОГО    # простой 1-2 минуты
bash /opt/baxi-guard/deploy/install.sh
```
`move-baxi.sh` копирует `/opt/linkhub` со старого сервера, пока бот работает, потом останавливает его там
(файлы остаются, автозапуск выключается), докопирует изменения, проверяет базу и запускает здесь с защитой
Бакси (`harden.sh`: сторож, лимиты логов, автозапуск). Не поднялся или что-то не так:
`move-baxi.sh rollback IP_СТАРОГО` вернёт данные и запустит бота на старом. Сайт: поменять в DNS A-записи на новый
IP, потом `bash /opt/linkhub/deploy/site.sh домен`.

Защита модератора: сервис с потолком памяти 320 МБ и одним ядром, только своя папка data, сторож
`baxi-guard-health.timer` (раз в 5 минут: упал или завис без пульса 10 минут → перезапуск, сообщение в Telegram;
раз в сутки копия базы в `data/backups`, 14 последних). API ботов только на 127.0.0.1.

## Убрать Гарда и тестовый стенд с сервера

От root:
```
curl -fsSLO https://raw.githubusercontent.com/dalmatinec/baxi-guard/guard-v1/deploy/wipe-server.sh
bash wipe-server.sh
```
Без вопросов удаляет /opt/baxi-guard, /opt/baxi-test, /opt/baxi-guard-test, сервисы baxi-*, их пользователей
и кеш pip. Боевой Бакси (/opt/linkhub, сервис linkhub, копии клиентов, сторож, сайт) не трогается. На сервере,
где боевой модератор работает с базой и сторожем, отказывается (снести всё же: `FORCE=1`).

## Установка на сервер

Сначала тестовый бот и тестовая группа, живые чаты не трогать.

```bash
git clone https://github.com/dalmatinec/baxi-guard /opt/baxi-guard
bash /opt/baxi-guard/deploy/install.sh     # спросит токен и твой Telegram ID
```

Потом связать с Бакси: `bash /opt/linkhub/deploy/guard-link.sh` (скрипт из репозитория baxi: общий ключ
в оба .env, адреса, `BAXI_BOT_ID`, перезапуск обоих ботов).

Скрипт установки создаст `/opt/baxi-guard/.env` (права 600), возьмёт `BAXI_API_KEY` из `/opt/linkhub/.env`, если он там
уже есть, иначе создаст новый (на экран не выводит). Сервис `baxi-guard.service`: Restart=always, MemoryMax=320M.
После добавления в группу дайте боту права: удаление сообщений, блокировка, закрепление, пригласительные ссылки
(кнопка "Добавить в чат" в /start просит их сама).

| Что | Команда |
|---|---|
| Обновить | `bash /opt/baxi-guard/deploy/update.sh` |
| Состояние | `systemctl status baxi-guard` |
| Логи | `journalctl -u baxi-guard -f` |
| Настройки | `nano /opt/baxi-guard/.env`, потом `systemctl restart baxi-guard` |

Токен, ключи и ID только в `.env` на сервере, в GitHub их нет. Пример: `.env.example`.

## Для разработчика

```
guard/
  __main__.py      запуск: python -m guard
  config.py        настройки из .env
  db.py            база SQLite (WAL): chats, warns, actions, stopwords, whitelist, domains, mods, members, outbox, kv
  perms.py         роли и права бота, кеш get_chat_member на минуту
  parse.py         разбор времени, цели и причины
  normalize.py     нормализация для стоп-слов
  links.py         ссылки, домены, скам-признаки
  actions.py       мут, бан, кик, предупреждения + запись в журнал и событие Бакси
  protect.py       стоп-слова, антиспам, режим атаки
  journal.py       строка в чат журнала
  access.py        работать ли в чате (оплата Бакси, своя подписка)
  baxi.py          клиент API Бакси и outbox
  api.py           свой API для Бакси (aiohttp, 127.0.0.1)
  ai.py            нейросеть для спорных случаев
  handlers/        auto (первым), common (/v, /chat), moderation, admin, settings
deploy/            install.sh, update.sh, baxi-guard.service
```

Docker (по желанию): `docker compose up -d --build`, лимиты в `docker-compose.yml`: 150 МБ памяти,
полъядра, 64 процесса, логи 3 по 10 МБ, файловая система только для чтения, кроме ./data.
У сервиса systemd те же лимиты (MemoryMax, CPUQuota, TasksMax).

Проверки: `pip install -r requirements-dev.txt`, потом `python -m pytest -q` и `ruff check .`
(в `pyproject.toml` стоит `--select F,E9,B`).

aiogram закреплён на 3.27-3.28: начиная с 3.29 он сам по себе занимает 115-155 МБ памяти на старте,
и сервис упирался бы в MemoryMax=150M. На 3.28 весь модератор около 105 МБ.
